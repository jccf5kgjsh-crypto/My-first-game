# My-first-game

This repository now includes a small animated city scene built with plain HTML, CSS, and JavaScript.

## Run it locally

Open `index.html` in a browser.

You can also serve it with a local web server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Files

- `index.html` – page layout
- `style.css` – visual styling
- `script.js` – animated city drawing

This is a simple city scene, ready to be expanded into a larger game.
